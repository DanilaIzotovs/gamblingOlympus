# gamblingOlympus
Projektu darbs
autori : Edmunds, Daņila, Maksims

Šis projekts ir kazino spēļu programmas piemērs, kas uzrakstīts Python valodā. Spēlētājs reģistrējas ar personīgo piekļuves kodu, piesakās sistēmā un pārvalda virtuālo naudas bilanci, kas tiek saglabāta JSON failā. Programma ļauj spēlēt vairākas kazino spēles, tostarp Blackjack, ruleti un slotu mašīnas, kā arī izmanto pamata profila un iemaksu funkcijas.

Lai izmantotu šo programmu, pārvietojiet to uz kādu mapi.

UZMANĪBU: NEKO NEVEIDOJIET PAŠI; VISS TIEK IZDARĪTS AUTOMĀTISKI.

Šobrīd ir pieejama izmēģinājuma versija — lai uzzinātu, cik daudz jūs potenciāli varētu laimēt, konsolē ierakstiet "test" un pārliecinieties paši!

Lai izmantotu konsoli, ievadiet sava konta kodu, lai pieteiktos, 'r', lai reģistrētos, vai 'q', lai izietu!
